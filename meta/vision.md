# Visión

KosmoTIC · Inter-IA evoluciona como infraestructura capability-centric: personas, IAs, datos y sistemas colaboran sin perder soberanía, memoria, evidencia, continuidad ni capacidad de decisión.

La web es una vista. Este repositorio es el núcleo **técnico versionado** para código, conocimiento público, experimentos y derivados. Las normas institucionales ratificadas conservan sus fuentes canónicas en Google Drive. Las taxonomías y vistas se derivan de datos y conocimiento, evitando atar la arquitectura a proveedores concretos. La [Carta Fundacional Inter-IA V1.0 ratificada](../docs/inter-ia/carta-fundacional-v1.0.md) orienta la incorporación de nodos; no concede permisos ni supone sincronización automática.
